Old Precision Bass by Fender. This prop was created during my classes at Game Art Institute.

The high-poly was created inside Maya. I used ZBrush to break some pieces in the pickguard that I felt would look better baked from the high-poly than created inside Painter. I then baked and created the textures inside Substance Painter, using Marmoset on the side to check the result.

The original ArtStation post also contains an interactive Marmoset asset that is not directly supported by the current portfolio renderer.

[View the original ArtStation project](https://cabilo.artstation.com/projects/k4rYlz)

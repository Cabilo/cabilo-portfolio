### 1. How "Customizable" is the Markdown schema later?
**Extremely customizable.** 
Think of the schema (`config.ts`) as a blueprint. Furthermore, the "Frontmatter" (the variables at the top of the markdown file) handles the strict data like titles and AOV images. But the **Body** of the markdown file (everything below the variables) is completely freeform. You can write 10 paragraphs of behind-the-scenes breakdowns, drop in 5 extra work-in-progress images, or write nothing at all. It adapts to whatever you type.

### 2. How do I add new projects (Markdown) in the future?
**Zero coding required.** 
When you finish a new 3D project, you will simply:
1. Go to `src/content/projects/`
2. Right-click -> New File -> `my-new-project.md`
3. Copy/paste the variables from an older project, swap the text/images, and write your breakdown.
4. Save and `git push`.
Astro will automatically detect the new file, generate a dedicated URL for it (`cabilo.vercel.app/projects/my-new-project`), and automatically insert a new thumbnail card at the exact top of your Portfolio Grid on the homepage.

You are absolutely correct to ask this. While we have been using ArtStation/Unsplash "internet links" for prototyping, **you will eventually host your own files directly in your repository.**

1. You will create a folder in your VS Code `public/` directory (e.g., `public/turntables/headscan/`).

3. In your Markdown file, you will simply reference the local path, like this:

     "/turntables/headscan/frame_02.jpg",

Because the `public/` folder hosts raw files exactly as they are, Astro reads them instantly. The schema allows for *both* external internet links (like your ArtStation ones) AND local paths (like `/turntables/...`). You can mix and match however you prefer!

<script>
  class TurntableScrubber extends HTMLElement {
    connectedCallback() {
      const display = this.querySelector('#tt-display') as HTMLImageElement;
      const counter = this.querySelector('#tt-counter') as HTMLElement;
      
      // Load the array of image URLs passed from Astro
      const framesData = this.getAttribute('data-frames');
      if (!framesData) return;
      
      const frames = JSON.parse(framesData) as string[];
      const totalFrames = frames.length;
      
      // Preload images for buttery smooth scrubbing
      // (This creates an invisible image tag in the browser's memory for every frame)
      const preloadedImages: HTMLImageElement[] = [];
      frames.forEach(src => {
        const img = new Image();
        img.src = src;
        preloadedImages.push(img);
      });

      let currentFrameIndex = 0;
      let isDragging = false;
      let startX = 0;
      let startFrame = 0;

      // Sensitivity: How many pixels you have to drag to move 1 frame.
      // Lower number = faster spin. Higher number = slower spin.
      const sensitivity = 10; 

      const updateFrame = (newIndex: number) => {
        // This math ensures it loops continuously! (Frame 72 loops back to Frame 1)
        currentFrameIndex = ((newIndex % totalFrames) + totalFrames) % totalFrames;
        
        display.src = preloadedImages[currentFrameIndex].src;
        // Update the visual frame counter
        counter.innerText = String(currentFrameIndex + 1).padStart(3, '0');
      };

      const startDrag = (e: MouseEvent | TouchEvent) => {
        isDragging = true;
        startX = ('touches' in e) ? e.touches[0].clientX : (e as MouseEvent).clientX;
        startFrame = currentFrameIndex;
        // Changes cursor to grabbing
        this.style.cursor = 'grabbing';
      };

      const doDrag = (e: MouseEvent | TouchEvent) => {
        if (!isDragging) return;
        e.preventDefault();
        
        const currentX = ('touches' in e) ? e.touches[0].clientX : (e as MouseEvent).clientX;
        const diffX = currentX - startX;
        
        // Calculate how many frames to move based on mouse movement
        const frameOffset = Math.floor(diffX / sensitivity);
        updateFrame(startFrame + frameOffset);
      };

      const stopDrag = () => {
        isDragging = false;
        this.style.cursor = 'ew-resize';
      };

      // Mouse Events
      this.addEventListener('mousedown', startDrag);
      window.addEventListener('mousemove', doDrag);
      window.addEventListener('mouseup', stopDrag);

      // Touch Events (for mobile)
      this.addEventListener('touchstart', startDrag, { passive: false });
      window.addEventListener('touchmove', doDrag, { passive: false });
      window.addEventListener('touchend', stopDrag);
    }
  }
  customElements.define('turntable-scrubber', TurntableScrubber);
</script>

export async function getStaticPaths() {

  const uniqueTags = new Set<string>();

  allProjects.forEach(p => p.data.softwareUsed.forEach(tag => uniqueTags.add(tag)));
  allLearning.forEach(l => l.data.tags.forEach(tag => uniqueTags.add(tag)));

  // 3. Generate a page for each tag
  return Array.from(uniqueTags).map((tag) => {
    // This converts "Unreal Engine 5" into a web-safe URL like "unreal-engine-5"

    const filteredProjects = allProjects.filter(p => p.data.softwareUsed.includes(tag));

    return {
      params: { tag: slug },
      props: { 
        tagName: tag, 
        projects: filteredProjects,

    Historically, hosting a headless CMS like Decap on Vercel required standing up a complex OAuth backend server. However, Decap CMS recently released a feature called **PKCE Auth**.

In your projects, you used the tag `"ZBrush"`. In your tutorials, you used `"zbrush"`. When Astro tries to build the website, it converts both of them to the URL `/tags/zbrush`. Astro sees two pages trying to claim the exact same URL, panics, and throws that warning. 

Because Astro is choking on the build process, **Vercel is silently refusing to update your website.** Every time you push, Vercel abandons the build and just keeps serving the old, broken version of the site (the one that routes to Netlify!).

---
import { getCollection } from 'astro:content';
import Layout from '../../layouts/Layout.astro';
import ProjectCard from '../../components/ProjectCard.astro';

export async function getStaticPaths() {
  const allProjects = await getCollection('projects');
  const allLearning = await getCollection('learning');

  const uniqueTags = new Set<string>();
  allProjects.forEach(p => p.data.softwareUsed.forEach(tag => uniqueTags.add(tag)));
  allLearning.forEach(l => l.data.tags.forEach(tag => uniqueTags.add(tag)));

  // We create a safety array to prevent duplicate URL collisions
  const processedSlugs = new Set<string>();
  const paths: any[] = [];

  Array.from(uniqueTags).forEach((tag) => {
    const slug = tag.toString().toLowerCase().replace(/\s+/g, '-').replace(/[^\w-]+/g, '');
    
    // Only build the page if we haven't already built this exact slug!
    if (!processedSlugs.has(slug)) {
      processedSlugs.add(slug);
      
      // Case-insensitive filtering so "ZBrush" and "zbrush" both match
      const filteredProjects = allProjects.filter(p => p.data.softwareUsed.some(t => t.toLowerCase() === tag.toLowerCase()));
      const filteredLearning = allLearning.filter(l => l.data.tags.some(t => t.toLowerCase() === tag.toLowerCase()));

      paths.push({
        params: { tag: slug },
        props: { tagName: tag, projects: filteredProjects, learning: filteredLearning },
      });
    }
  });

  return paths;
}

const { tagName, projects, learning } = Astro.props;
